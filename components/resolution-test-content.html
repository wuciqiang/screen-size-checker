How to read screen resolution results

Screen resolution is the width and height a browser reports in CSS pixels. The viewport is the page workspace left after browser controls, sidebars, scrollbars, and mobile UI take space. A 1920 x 1080 screen can have a smaller viewport when a window is not maximized. Record both values when diagnosing layout behavior.

Device pixel ratio, or DPR, relates CSS pixels to device pixels. DPR helps explain responsive breakpoints, image density, and screenshots, but it does not identify a panel model or native mode. Estimated pixels are calculated from browser dimensions and DPR, so zoom and operating-system scaling can change the report without changing the physical display.

How to read the live result

  1. Start with screen size and viewport size. Record both when reporting a layout issue.
  2. Check DPR and aspect ratio to understand density and shape.
  3. Use available area and browser outer window to explain reduced workspace.
  4. Compare orientation and color depth when testing a device or screenshot workflow.

Troubleshoot blurry or unexpected results

If text looks soft, reset browser zoom to 100 percent and compare another browser. Check display settings and the application that looks blurry, then reload this page. A browser-reported value can differ from a monitor specification because zoom, scaling, window chrome, and rendering choices affect the page coordinate system. This checker intentionally reports browser-observable measurements rather than claiming certainty about a panel's native mode.

Resolution checker FAQ

Why is my viewport smaller than my screen?

Browser controls and mobile interface areas reduce the space available to a web page, so viewport dimensions are often smaller than screen dimensions.

Does DPR reveal my native panel resolution?

No. DPR is a browser-reported scale relationship, not a guarantee of native panel resolution.

What does orientation mean?

Orientation labels the reported screen as landscape, portrait, or square by comparing its width and height.

What is available area?

Available area is the browser-reported screen space that remains available around system UI.

Can I share these results?

On supported mobile devices, the Share button uses native sharing. On desktop, when sharing is unavailable, or when native sharing fails, it copies the canonical checker URL.

Do values update when I resize?

Yes. Values refresh after a resize or orientation change.
